# Secure Railway Reservation System (SRRS) — Final Student Handover Package

This is the complete student-facing handover package for the Software Security
course project.

Start with:

1. `STUDENT_HANDOVER_CHECKLIST.md`
2. `common/START_HERE.md`
3. `docs/Secure_Railway_Reservation_System_Project_Specification.pdf`

Then use the language-specific source folders and the test resources under
`tests/`.

The package follows:

**BUILD → BREAK → ANALYZE → COMPARE → FIX → RETEST → COMPARE → REPORT**

The private TA expected-result/evaluation matrix is intentionally excluded.

## Final Security Assessment Rule

The assessment covers the complete security-testing lifecycle. Students are expected to investigate all applicable security requirements, preserve reproducible evidence, analyze the findings, fix all identified and technically applicable vulnerabilities, and retest the original attacks.
