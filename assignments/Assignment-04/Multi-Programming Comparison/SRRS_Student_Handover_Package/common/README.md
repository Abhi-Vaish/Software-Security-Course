# Secure Railway Reservation System — Student Starter Package

This package supports a cross-language software-security experiment using
Python, Java, C++, and Rust.

## Start Here

1. Read the **Project Specification** in `docs/`.
2. Read the documents in `common/`.
3. Build and run each language implementation.
4. Follow the project workflow:

**BUILD → BREAK → ANALYZE → COMPARE → FIX → RETEST → COMPARE → REPORT**

The supplied code is intentionally not a completed secure implementation.
Students are expected to investigate security behaviour, analyze findings,
implement appropriate fixes, retest, and compare the four languages.
